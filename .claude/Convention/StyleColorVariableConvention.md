## Color Variable Guide

### 1. 기본 원칙

- **변수 사용 필수**: 모든 색상 코드는 `#fefefe`와 같은 하드코딩된 값을 사용하지 않고, 반드시 theme.css 파일에 존재하는 **정의된 CSS 변수(`--color-*`)를 사용**합니다.
- **미 존재 변수 :** 필요하지만 존재하지 않는 컬러의 경우 **변수 추가에 대한 제안 후 값을 사용**

### 2. 변수 사용 지침

- **투명도(Opacity) 처리**: 색상에 투명도를 적용할 때는 새로운 변수를 만들기보다 `rgba` 또는 `hsla`를 활용
  - **권장 방식**: `background-color: rgba(var(--color-primary-rgb), 0.5);`
  - 이를 위해 색상 변수를 RGB 값으로 별도 정의해두면 편리 (`-color-primary-rgb: 0, 123, 255;`)
- **가장 구체적인 변수 사용**: 여러 변수가 적용될 수 있을 때는 가장 **의미가 명확하고 구체적인** 변수를 선택
  - **예시**: 헤더의 텍스트 색상으로 `-color-black` 대신 `-color-text-header`를 사용

### 3. 신규 변수 추가 프로세스

**"변수 추가 제안"** 규칙을 더 구체화합니다.

- **제안 양식**: 새 변수 제안 시 **[HEX 코드, 변수명(제안), 주요 사용처]** 정보를 포함하여 요청하도록 규칙을 정함
- **중복 확인**: 새 변수를 제안하기 전에, 디자인 시스템이나 `theme.css` 파일 내에서 **유사한 색상이나 용도의 변수가 이미 있는지 반드시 확인**하는 절차를 추가
