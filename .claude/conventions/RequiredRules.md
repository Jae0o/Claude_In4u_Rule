# Required Rules Guide

## Required Guidelines Management

- **Core Document**: The rules within `RequiredRules.md` document are a collection of mandatory rules that must be strictly followed
- **Highest Priority**: These rules must be prioritized above all other considerations for every request
- **Additional Verification**: After completing any requested work, perform additional verification to ensure these rules have been properly applied

---

## 1. Rule Priority System

- **Highest Priority**: Rules in `RequiredRules.md` take precedence over all other guidelines
- **Mandatory Compliance**: No exceptions allowed unless explicitly stated in the rules
- **Conflict Resolution**: When conflicts arise with other guidelines, `RequiredRules.md` always takes priority

---

## 2. RequiredRules.md Change Process

- **Modification Prohibited**: Claude Code cannot directly modify the `RequiredRules.md` file
- **Change Proposals**: Only proposals are allowed for adding/modifying/deleting rules
- **Approval Required**: All rule changes can only be applied after approval
- **Immediate Application**: Approved new rules must be immediately applied to all subsequent work

---

## 3. Verification Process

- **Pre-work Check**: Review `RequiredRules.md` before starting any work
- **During Work Reference**: Continuously reference rules while working
- **Post-work Validation**: Final verification of all applicable rules after completion
- **Documentation**: Document applied rules and how they were implemented

---

## 4. Rule Violation Response

- **Immediate Stop**: Immediately halt work when rule violations are detected
- **Violation Analysis**: Analyze the cause and scope of violations
- **Corrective Action**: Immediately correct to comply with rules
- **Re-verification**: Re-verify full rule compliance after corrections
- **Reporting**: Report violations and corrective actions taken

---

## 5. CSS Theme Absolute Rules

- **Absolutely Prohibited**: Adding/modifying/deleting variables in `theme.css` file is absolutely prohibited
- **Proposal Required**: Any CSS theme changes require prior proposal and approval request
- **Convention Reference**: For detailed theme matters, must refer to CSS Theme Convention Guide
- **Approval Pending**: No theme-related changes can be performed without approval
- **No Emergency Exceptions**: Theme changes are prohibited even in emergency situations without exception
- **Alternative Solutions**: Provide alternative methods when theme changes are needed

---

## Required Rules Application Checklist

- [ ] Have you reviewed the `RequiredRules.md` file?
- [ ] Have you identified all rules applicable to the current task?
- [ ] Have all rules been properly applied to the code/work?
- [ ] **If CSS theme changes are needed, have you received approval through proposals?**
- [ ] **When working on theme-related tasks, have you referenced the CSS Theme Convention Guide?**
- [ ] Have you avoided directly modifying the `theme.css` file?
- [ ] Have you properly resolved any conflicts between rules?
- [ ] Does the final output comply with all required rules?
