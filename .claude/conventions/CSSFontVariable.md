## Font Size Guide

### **1. 기본 원칙**

1. **확장 가능한 단위**: 모든 폰트 크기는 `rem` 단위를 사용하여 웹 접근성을 준수 (`1rem = 16px` 기준)
2. **변수 사용**: CSS 코드 작성 시 `12px`와 같은 고정값을 직접 사용하지 않고, 반드시 **`--font-size-*` 변수를 사용**해야 합니다.

---

### **2. 폰트 사이즈 토큰(Token) 정의**

1. **`--font-size-12`**

- **값**: `12px` (`0.75rem`)
- **설명**: 가장 작은 보조 텍스트.
- **주요 용도**: 메타데이터, 저작권 정보, 테이블 내 부가 설명.
- **구체적인 사용 예시**:
  - 페이지네이션의 현재/전체 페이지 정보
  - 테이블 셀 내부의 작은 주석
  - 버튼 내부의 보조 아이콘 텍스트

1. **`--font-size-14`**

- **값**: `14px` (`0.875rem`)
- **설명**: 시스템의 표준 본문 텍스트.
- **주요 용도**: 일반적인 문단, 폼 요소, 기본 버튼.
- **구체적인 사용 예시**:
  - 대화 내용, 설명 등 대부분의 텍스트
  - 입력 필드(Input), 텍스트 영역(Textarea)의 기본 텍스트
  - 모달(Modal) 및 드롭다운 메뉴의 내용
  - 사이드바 및 네비게이션 메뉴 항목

1. **`--font-size-16`**

- **값**: `16px` (`1rem`)
- **설명**: 기본 본문보다 중요한 내용을 강조
- **주요 용도**: 강조 문단, 사이드바 메뉴, 중요한 정보 안내.
- **구체적인 사용 예시**:
  - 로그인 페이지의 입력 필드 레이블
  - AI 채팅 에디터의 입력 텍스트
  - 스토어 페이지의 상세 설명 본문

1. **`--font-size-18`**

- **값**: `18px` (`1.125rem`)
- **설명**: 콘텐츠 섹션의 제목
- **주요 용도**: 섹션 제목(h3), 모달 타이틀, 테이블 헤더.
- **구체적인 사용 예시**:
  - 스토어 페이지 내 '추천', '인기' 등 각 섹션의 제목
  - 데이터 테이블의 헤더(thead)
  - 대시보드 그리드의 제목

1. **`--font-size-20`**

- **값**: `20px` (`1.25rem`)
- **설명**: 페이지의 주요 제목
- **주요 용도**: 페이지 제목(h2), 중요한 모달 헤더.
- **구체적인 사용 예시**:
  - 'My AI', 'AI 스토어' 등 각 페이지의 메인 제목
  - 경고 또는 확인 모달 창의 제목
  - 사이드바 상단의 큰 타이틀

1. **`--font-size-25`**

- **값**: `25px` (`1.5625rem`)
- **설명**: 가장 중요한 대형 타이틀, 브랜딩이나 핵심 메시지
- **주요 용도**: 최상위 페이지 타이틀(h1), 랜딩 페이지 헤더.
- **구체적인 사용 예시**:
  - 서비스 소개 랜딩 페이지의 헤드라인
  - AI 채팅 시작 전 인트로 화면의 메인 제목

### 3. CSS 변수 지정 예시

```css
:root {
  --font-size-12: 0.75rem; /* 또는 12px */
  --font-size-14: 0.875rem; /* 또는 14px */
  --font-size-16: 1rem; /* 또는 16px */
  --font-size-18: 1.125rem; /* 또는 18px */
  --font-size-20: 1.25rem; /* 또는 20px */
  --font-size-25: 1.5625rem; /* 또는 25px */
}
```

## Font weight Guide

### **1. 기본 원칙**

1. **변수 사용**: CSS 코드 작성 시 `font-weight: 500;`과 같은 숫자 값을 직접 사용하지 않고, 의미가 **명확한 `--font-weight-*` 변수를 사용**해야 합니다.
2. **제한된 사용**: 시각적 계층을 명확히 하기 위해 정의된 4가지 굵기 외에는 사용을 지양합니다.
3. **`bold` 키워드**: CSS의 `bold` 키워드는 `700`에 해당하므로, 일관성을 위해 `--font-weight-bold` 변수를 사용합니다.

### **2. 폰트 굵기 토큰(Token) 정의**

1. **`--font-weight-normal`**

- **값**: `400`
- **설명**: 가장 기본적인 본문 텍스트의 표준 굵기
- **주요 용도**: 긴 문단의 읽기용 콘텐츠, 설명 텍스트.
- **구체적인 사용 예시**:
  - 서비스의 기본 문단 및 설명
  - 모달(Modal) 내부의 상세 내용
  - 사이드바 메뉴의 기본 텍스트

1. **`--font-weight-medium`**

- **값**: `500`
- **설명**: 시스템 전반에서 **가장 많이 사용되는 중간 강조** 굵기
- **주요 용도**: 라벨, 버튼, 약한 강조가 필요한 텍스트.
- **구체적인 사용 예시**:
  - 대부분의 버튼 텍스트
  - 입력 필드(Input)의 라벨
  - 데이터 테이블의 헤더(thead)
  - AI 채팅 모델 선택 옵션
  - 스토어 페이지의 제품 정보

1. **`--font-weight-semibold`**

- **값**: `600`
- **설명**: 제목이나 중요한 정보를 강조할 때 사용되는 굵기
- **주요 용도**: 페이지 및 섹션 제목, 중요 알림 메시지.
- **구체적인 사용 예시**:
  - 로그인, 에러 페이지의 메인 제목
  - 경고 및 알림 메시지
  - AI 채팅 답변의 제목
  - 모바일 화면의 헤더 텍스트

1. **`--font-weight-bold`**

- **값**: `700`
- **설명**: 가장 높은 수준의 강조가 필요할 때 제한적으로 사용
- **주요 용도**: 핵심 키워드, 숫자, 가장 중요한 경고.
- **구체적인 사용 예시**:
  - 음성 스트리머의 핵심 단어 강조
  - 시스템의 심각한 오류나 경고 메시지

### **3. CSS 변수 지정 및 사용 예시**

```css
:root {
  --font-weight-normal: 400;
  --font-weight-medium: 500;
  --font-weight-semibold: 600;
  --font-weight-bold: 700;
}
```
